# MTG Online Table

一个网页端万智牌自由对战桌原型。程序维护牌库、手牌、战场、墓地、放逐区、生命和法术力池；不内置规则判定，操作合法性由双方玩家自行确认。

## 使用方式

启动本地服务后访问：

```bash
python3 server.py
```

然后打开 `http://127.0.0.1:5173/`。

为了模拟双方同步：

1. 打开两个浏览器标签页。
2. 第一个标签选择“玩家一”，第二个标签选择“玩家二”。
3. 任一方操作后，另一个标签会通过浏览器本地通道和服务端状态轮询自动同步。

如果要让不在同一台电脑上的玩家加入，需要让对方访问运行 `server.py` 的这台机器：

- 同一局域网内可访问 `http://主机局域网IP:5173/`。
- 不在同一局域网时，需要使用端口转发、VPN，或 ngrok / Cloudflare Tunnel 这类隧道工具，把本机的 `5173` 端口暴露出去。
- 当前实现没有身份校验，拿到地址的人都能加入并操作这张牌桌。

日期压缩包 `mtg-online-2026-06-12.zip` 包含运行需要的文件：

## 当前功能

- 单牌桌线上同步：所有访问同一服务地址的浏览器共享同一份牌桌状态。
- 无身份校验、无作弊防护，完全信任玩家。
- 双方牌桌动态同步。
- 顶部控制区包含连接状态、同步计时器、撤销上一步、硬币/D6/D20 随机工具，以及查询工具。查询默认先查卡片、未命中后查机制；搜索框为空并获得焦点时会展开 `Cards:`、`Mechanics:`、`Translate:` 候选前缀，用于指定卡片、机制或本地术语翻译。
- 双方共享一个大战场，中线分隔双方半场；对手半场会按面对面视角倒置显示。
- 自己和对手状态栏是浮在战场上方的折叠卡片：标题栏可拖动，位置只保存在当前浏览器标签页，不会同步给对手；自己的手牌围绕中间战场展示，对手手牌和区域放在对手状态栏中查看。
- 战场是可调高度的网格画布，卡牌可重叠摆放，放置时会吸附到网格点。
- 战场支持同步标记：可以添加文本、颜色和内置符号标记，标记可拖动，右键可删除。
- 战场工具栏支持记录两个对象的指向关系：进入记录模式后依次选择源对象和目标对象，再在指针旁的操作框中选择操作，日志会记录源对象对目标对象的操作。
- 可以把自己的牌拖到战场任意网格位置，或拖到手牌、墓地、放逐区、牌库；拖到牌库时会选择牌库顶、牌库底或洗入牌库，程序不判定是否合法。
- 牌库、墓地、放逐区可以点击展开；对手手牌只显示背面和数量。
- 手牌和战场上的牌显示完整卡面。
- 生命和法术力池由程序维护。
- 抓牌、上场、入墓、放逐、回手、回库、横置、重置等自由操作。
- 支持按牌名创建衍生物，并通过 Scryfall API 查询衍生物卡图。
- 支持导入牌表，格式示例：

```text
4 Lightning Bolt
8 Island
2 Snapcaster Mage
SB: 2 Negate
```

导入时会忽略 `Sideboard` 区块和 `SB:` 备牌行；支持 `4 Card Name` 和 `4x Card Name` 数量写法。程序会在浏览器中直接调用 Scryfall API 查询英文牌图，并直接加载 `cards.scryfall.io` 图片；不再依赖本地后端卡图代理、dragonbox 或本地图片目录。法术力和战场标记符号使用 Scryfall 的符号 SVG。无法联网或找不到牌时，会显示简化占位卡面。

如果部署到纯静态平台，卡图查询仍可工作，因为它不依赖 `server.py`。但线上牌桌同步仍需要 `/api/table/state` 后端；只上传到静态托管时，跨设备同步不会生效。

## 后续建议

当前联机方式是单牌桌 HTTP 自动同步：

- 客户端操作后 POST 整张牌桌状态到 `/api/table/state`。
- 客户端每秒 GET `/api/table/state` 拉取最新状态。
- 服务端只保存一份内存状态，重启服务会清空线上牌桌。
- 不区分玩家身份，不做合法性或作弊校验。
